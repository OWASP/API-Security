# Sürüm Notları

Bu, OWASP API Security Top 10'un üç veya dört yılda bir periyodik olarak
güncellemeyi planladığımız ilk sürümüdür.

Bu sürümden farklı olarak, sonraki sürümlerde güvenlik sektörünü bu çabaya
dahil edecek şekilde herkese açık bir veri çağrısı yapmak istiyoruz. Bu
sürümün nasıl oluşturulduğuyla ilgili daha fazla ayrıntıyı [Metodoloji ve
Veriler][1] bölümünde bulabilirsiniz. Güvenlik riskleri hakkında daha fazla
bilgi için lütfen [API Güvenliği Riskleri][2] bölümüne bakın.

Son birkaç yılda uygulama mimarisinin önemli ölçüde değiştiğini belirtmekte
fayda var. Günümüzde API'ler; mikroservisler, Tek Sayfa Uygulamaları (SPA),
mobil uygulamalar, IoT vb. gibi bu yeni mimaride çok önemli bir rol
oynamaktadır.

OWASP API Security Top 10, modern API güvenliği sorunları hakkında
farkındalık oluşturmak için gerekli bir çalışmaydı. Bu, [Teşekkürler][3]
bölümünde listelenen çok sayıda gönüllünün büyük emeği sayesinde mümkün
olabilmiştir. Teşekkürler!
